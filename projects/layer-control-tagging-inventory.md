# Layer Control, Tagging, and Inventory

## Project overview

These routines support drafting and documentation tasks that recur across industrial piping drawings.

## Workflow and deliverables

DN drafts pipework by nominal diameter. LayerControl groups layers so they can be shown or hidden together. ExportarEtiquetas reads the original component tags and exports an inventory to CSV.

## Project evidence

- Control the visibility of related AutoCAD layers from a single panel.
