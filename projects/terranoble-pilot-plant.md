# Terranoble and Pilot Plant

## Project overview

The model brings equipment, facility geometry, and utility routing together in an AutoCAD layout for the Terranoble site and its pilot plant.

## Workflow and deliverables

The portfolio includes a top-view screenshot and an interactive model extracted from the DWG. The viewer retains object and layer colors to help readers distinguish utility systems while orbiting the facility.
